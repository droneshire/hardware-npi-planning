The following screenshots are referenced in the README.md:

1. **dashboard.png** - Executive dashboard showing portfolio overview and resource utilization

## Screenshot Guidelines

- **Format**: PNG format recommended
- **Size**: 1920x1080 or similar (16:9 aspect ratio)
- **Quality**: High resolution, clear text
- **Content**: Show realistic data, not placeholder text
- **Privacy**: Ensure no sensitive data is visible

## How to Add Screenshots

1. Take screenshots of the running application
2. Save them in this directory with the names listed above
3. Update the README.md if you add additional screenshots
